# Building from source

Everything in the releases can be rebuilt from this repository. This page is for developers. To simply use Meu Dot, follow [Getting started](getting-started.md).

| Part | Toolchain |
| --- | --- |
| Firmware | [ESP-IDF 5.5.5](https://docs.espressif.com/projects/esp-idf/en/v5.5.5/esp32s3/get-started/). The Waveshare BSP 3.0.0 and LVGL 9.5.0 come from the component manager, pinned in `dependencies.lock`. |
| Android app | JDK 17, Android SDK Platform 35, Build Tools 36.1.0, NDK r28c, CMake and Ninja. There is no Gradle. |
| Bridge | Node.js 22.13+ and a ChatGPT Sites project. |
| Simulator and art | Clang with the `wasm32` target and `wasm-ld`; Python 3 with Pillow. |
| Host tests | A C compiler, JDK 17 and Node.js. |

## Firmware

```sh
. $IDF_PATH/export.sh            # or the ESP-IDF terminal on Windows
cd firmware
idf.py build
idf.py -p PORT flash monitor      # writes bootloader, partition table and app
```

- `sdkconfig` is committed, so a build reproduces the released configuration. `sdkconfig.defaults` holds only the essentials.
- The partition table ([`partitions.csv`](../../firmware/partitions.csv)) has NVS (pairing and settings) at `0x9000` and a single 6 MB factory app at `0x10000`. Writing only the app image keeps pairing.
- To make a single full image for `0x0`:
  ```sh
  cd build
  python -m esptool --chip esp32s3 merge_bin -o meu-dot-full.bin \
    --flash_mode dio --flash_size 16MB --flash_freq 80m \
    0x0 bootloader/bootloader.bin 0x8000 partition_table/partition-table.bin 0x10000 dot_de_bolso.bin
  ```
- The board's USB-C port is the ESP32-S3's native USB Serial/JTAG. It needs no driver, and the console runs at 115200 baud.

### Where things live

| File | Contents |
| --- | --- |
| `firmware/main/main.c` | Display start, LVGL canvas, the 20 ms UI tick and power-off. |
| `firmware/main/voice.c` | Recording, the microphone uplink task, reply playback and buffering. |
| `firmware/main/link_ble.c` | NimBLE GATT server, pairing, capability negotiation and the packet queue. |
| `firmware/main/battery.c` | AXP2101 reading (read only). |
| `firmware/main/settings.c` | Buttons, debounce and settings saved in NVS. |
| `interface/dot_ui.c` | Every screen, gesture and animation, plus partial repaint. |
| `interface/art_data.inc` | Character frames and fonts, generated by `tools/recursos.py`. |

## Android app

```sh
export ANDROID_HOME=/path/to/android-sdk
export JAVA_HOME=/path/to/jdk-17
export ANDROID_NDK_HOME=/path/to/android-ndk-r28c
bash android/build.sh /path/to/output     # outside the repository
```

The script:

1. downloads four pinned JARs (Java-WebSocket, MessagePack, SLF4J) and checks their SHA-256;
2. builds `libdot_voice.so` from a pinned whisper.cpp revision for arm64. Set `WHISPER_SOURCE_DIR` to reuse a checkout;
3. compiles the Java sources with `javac`, dexes them with `d8`, aligns the APK to 16 KB pages and signs it.

> [!IMPORTANT]
> On the first build, `build.sh` creates a signing key, `debug.p12`, in the output folder. **Keep it private and keep it.** Android only installs an update over an existing app when both are signed with the same key. The key is never part of this repository. Set `MEU_DOT_KEYSTORE_PASS` to protect it with your own password; the default, `android`, only suits a throwaway key.

The app has no third-party UI framework. `Design.java` holds the palette and layout helpers, `Companion.java` the service, `Radio.java` the Bluetooth protocol, and `VoiceOutput.java`, `CloudVoice.java` and `OfflineVoice.java` the voice providers.

## Bridge

See [Bridge](bridge.md). To run its tests:

```sh
cd bridge && node --test tests/bridge.test.mjs
```

## Simulator

The simulator compiles `interface/dot_ui.c` to WebAssembly and embeds it in a single HTML file:

```sh
bash tools/previa.sh docs/simulator/index.html   # needs clang (wasm32) and wasm-ld
```

## Character art

```sh
python tools/ambar.py      # blue originals → art/quadros-ambar.png and art/personagem.png
python tools/recursos.py   # art → interface/art_data.inc (RGB565 + 4-bit mask, fonts)
python tools/repo/banner.py
```

## Tests

```sh
sh tests/run.sh
```

| Suite | Checks |
| --- | --- |
| `tests/firmware/voice` | Builds the real `voice.c` on the host with AddressSanitizer and UBSan. Stub codec, GATT, queue and scheduler; the uplink runs as a real thread. 18 scenarios: streaming, cancellation, 30 s limits, underruns, pre-roll, discard, recording binding and more. |
| `tests/firmware/ui` | Gestures, 30 s recording limit, shortcuts, lock screen and power-off (`controls.c`); AXP2101 decoding (`BatteryTest.c`). |
| `tests/android` | Gemini and Fish contracts, PCM resampling, BLE framing, the 1 s start rule, timing correlation, notice and decision safety. |
| `bridge/tests` | Authentication, signatures, retries, receipts, queue order and correlation. |

## Debugging

- **Board:** `idf.py -p PORT monitor` shows the `dot_ble`, `dot_audio`, `dot_tempo` and `dot_ui` tags.
- **Phone:**
  - `adb logcat -s MeuDotBle MeuDotTiming MeuDotVoz` shows the link, the timing of every step and voice fallbacks.
  - The last reply's audio is saved to `Android/data/br.bolso.dot/files/ultima-resposta.wav`.
